# Cadence

An adaptive AI running coach - installable web app.

**Live: https://orrimgames.github.io/cadence/**

- Adaptive training plans (5K to marathon) that re-adjust when runs are logged or missed
- Live GPS run tracking with pace and mile splits
- Coaching paces from a VDOT fitness model
- Local-first: all data stays on your device

An orrimgames build.
